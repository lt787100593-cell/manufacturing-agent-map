Selection Methodology

为什么是这10个场景

每一个场景的选定都经过严格的筛选标准和多维度交叉验证，不是拍脑袋的结果

四条选型原则

1 通用性

80%以上的制造企业存在此场景。不绑定特定行业（如半导体光刻、制药GMP），确保场景可跨行业复制。

2 痛点普遍性

业务部门高频提到的共性痛点；管理层经营决策中的高频关注点。排除偶发性问题和非经营相关的行政性问题。

3 数据可得性

所需数据在MES/ERP/QMS/WMS等系统中普遍存在。不依赖IoT传感器实时数据或外部数据源。

4 BI能力匹配

FBN原生能力可完全支撑。指标卡、图表、筛选器、联动、预警均可实现，不依赖机器学习算法。

场景选型从三个维度交叉验证：制造业价值链映射确保端到端无盲区，部门映射确保每个业务部门都有对应场景，价值密度确保每个场景都能快速产出可演示的分析成果。

ROI可量化 — 改善效果可以用财务指标衡量

Scenario Synergy

场景协同

10个场景不是孤立的，它们之间存在天然的数据关联和分析协同

协同关系

协同关系场景组合协同价值
研发→生产11-BOM + 01-生产效率BOM变更 → 生产工艺调整 → 效率/成本影响
研发→质量11-BOM + 03-质量BOM变更 → 新材料/工艺 → 质量风险评估
效率→成本01-生产效率 + 07-成本设备效率低 → 单位成本高，定位效率改善的财务价值
质量→成本03-质量 + 07-成本不良率高 → 质量成本高，量化质量改善的ROI
采购→库存04-供应商 + 05-库存与交付供应商交期不准 → 安全库存高 → 影响交付
生产→交付01-生产效率 + 05-库存与交付生产计划未达成 → 客户交付延迟，端到端追溯
售后→质量06-售后 + 03-质量售后故障数据 → 反馈到生产质量改善
